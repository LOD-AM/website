Example queries

Each query answers a research question on the released data. Open it in the query editor to run it, change it or download the result. The queries follow the LOD-AM conventions; values are returned as reported in the publications.

  1. Lead isotope ratios of the finds from a site
  2. Finds of a type, with material, context and dating
  3. Analyses in which an element was not detected
  4. Arsenic contents of the finds from contexts of one phase
  5. Records documented in a publication
  6. Types of the LOD-AM typology and their Getty AAT matches

Lead isotope ratios of the finds from a site

Which lead isotope ratios have been reported for the finds from Arslantepe, and in which context was each find made?

Columns: ?find, ?findNumber, ?context, ?isotope, ?reference, ?ratio. Conventions: finds and their contexts (features, finds without a feature), sampling, lead isotope ratios.

Note: change the site name to query another site. Ratios as reported (dimensionless). A find made in a feature of a feature (a grave in a kurgan) is found through crm:P46i_forms_part_of+.

Open in the query editor Source (01-lead-isotopes-of-a-site.rq)

PREFIX crm:        <http://www.cidoc-crm.org/cidoc-crm/>
PREFIX crmsci:     <http://www.cidoc-crm.org/extensions/crmsci/>
PREFIX crmarchaeo: <http://www.cidoc-crm.org/extensions/crmarchaeo/>
PREFIX afx:        <http://purl.allotrope.org/ontologies/property#>
PREFIX afr:        <http://purl.allotrope.org/ontologies/result#>
PREFIX qudt:       <http://qudt.org/schema/qudt#>
PREFIX rdfs:       <http://www.w3.org/2000/01/rdf-schema#>
PREFIX wd:         <http://www.wikidata.org/entity/>

SELECT ?find ?findNumber ?context ?isotope ?reference ?ratio WHERE {
  ?site a crm:E27_Site ; rdfs:label "Arslantepe"@en .
  # The find's context: a feature of the site, or (finds without a feature) the site's place
  {
    ?feature crm:P46i_forms_part_of+ ?site .
    ?find crmarchaeo:AP21i_is_contained_in ?feature .
    ?feature rdfs:label ?context . FILTER (lang(?context) = "en")
  } UNION {
    ?site crm:P53_has_former_or_current_location ?place .
    ?find crm:P53_has_former_or_current_location ?place .
    BIND ("(site, no feature)" AS ?context)
  }
  ?find a crm:E22_Human-Made_Object .
  OPTIONAL { ?find crm:P1_is_identified_by/crm:P190_has_symbolic_content ?findNumber }
  # find -> sampling -> sample -> analysis -> its results
  ?sampling crmsci:O3_sampled_from ?find ; crmsci:O5_removed ?sample .
  ?analysis afx:AFX_0000399 ?sample ; afx:AFX_0000395 ?result .
  ?result a afr:AFR_0002368 ;                 # analyte molar ratio
          afx:AFX_0002816 ?nuclide ;          # analyte (numerator)
          afx:AFX_0001550 ?referenceNuclide ; # reference (denominator)
          qudt:numericValue ?ratio .
  VALUES (?nuclide ?isotope) { (wd:Q18883429 "lead-204") (wd:Q18883438 "lead-206") (wd:Q18883443 "lead-207") (wd:Q16670466 "lead-208") }
  VALUES (?referenceNuclide ?reference) { (wd:Q18883429 "lead-204") (wd:Q18883438 "lead-206") (wd:Q18883443 "lead-207") (wd:Q16670466 "lead-208") }
}
ORDER BY ?findNumber ?isotope

Finds of a type, with material, context and dating

Which awls are there, what are they made of, where were they found and to which phase does their context date?

Columns: ?find, ?findNumber, ?material, ?feature, ?phase. Conventions: typology (SKOS), finds and their contexts, dating of contexts (not of objects).

Note: change the type label ("awl"@en; German labels such as "Pfriem"@de work too). Material is a Getty AAT concept.

Open in the query editor Source (02-finds-of-a-type.rq)

PREFIX crm:        <http://www.cidoc-crm.org/cidoc-crm/>
PREFIX crmarchaeo: <http://www.cidoc-crm.org/extensions/crmarchaeo/>
PREFIX rdfs:       <http://www.w3.org/2000/01/rdf-schema#>
PREFIX skos:       <http://www.w3.org/2004/02/skos/core#>

SELECT ?find ?findNumber ?material ?feature ?phase WHERE {
  ?type skos:inScheme <https://lod-am.net/id/typology> ; skos:prefLabel "awl"@en .
  ?find a crm:E22_Human-Made_Object ; crm:P2_has_type ?type .
  OPTIONAL { ?find crm:P1_is_identified_by/crm:P190_has_symbolic_content ?findNumber }
  OPTIONAL { ?find crm:P45_consists_of ?material }
  OPTIONAL {
    ?find crmarchaeo:AP21i_is_contained_in ?f .
    ?f rdfs:label ?feature . FILTER (lang(?feature) = "en")
    # a context is dated, the find through its context
    OPTIONAL { ?f crm:P8i_witnessed/rdfs:label ?phase . FILTER (lang(?phase) = "en") }
  }
}
ORDER BY ?findNumber

Analyses in which an element was not detected

In which chemical analyses was tin looked for but not detected?

Columns: ?analysis, ?label, ?object. Conventions: chemical composition, "not detected" (lod-am:not_detected) as distinct from "not analysed".

Note: "Not detected" is a result without a value, typed lod-am:not_detected. An element that was not analysed has no result at all, so it doesn't appear here. Elements are ChEBI atoms (tin = CHEBI_27007, arsenic = CHEBI_27563, lead = CHEBI_25016).

Open in the query editor Source (03-element-not-detected.rq)

PREFIX crm:    <http://www.cidoc-crm.org/cidoc-crm/>
PREFIX crmsci: <http://www.cidoc-crm.org/extensions/crmsci/>
PREFIX afx:    <http://purl.allotrope.org/ontologies/property#>
PREFIX afr:    <http://purl.allotrope.org/ontologies/result#>
PREFIX rdfs:   <http://www.w3.org/2000/01/rdf-schema#>
PREFIX obo:    <http://purl.obolibrary.org/obo/>

SELECT ?analysis ?label ?object WHERE {
  ?result a afr:AFR_0002099 ;                 # mass fraction
          afx:AFX_0002816 obo:CHEBI_27007 ;   # tin
          crm:P2_has_type <https://lod-am.net/id/not_detected> .
  ?analysis afx:AFX_0000395 ?result ; rdfs:label ?label . FILTER (lang(?label) = "en")
  ?analysis afx:AFX_0000399 ?sample .
  ?sampling crmsci:O5_removed ?sample ; crmsci:O3_sampled_from ?object .
}
ORDER BY ?label

Arsenic contents of the finds from contexts of one phase

Which arsenic contents have been reported for finds from contexts dated to Arslantepe VIB1, and in which publication?

Columns: ?find, ?findNumber, ?context, ?arsenic, ?upperLimit, ?notDetected, ?unit, ?publication. Conventions: dating of contexts, chemical composition, "not detected", upper limits ("< x").

Note: values as reported (mass fraction, unit as given). Exactly one of arsenic, upperLimit and notDetected is set per row. Finds without a feature are dated through their site.

Open in the query editor Source (04-arsenic-of-a-phase.rq)

PREFIX crm:        <http://www.cidoc-crm.org/cidoc-crm/>
PREFIX crmsci:     <http://www.cidoc-crm.org/extensions/crmsci/>
PREFIX crmarchaeo: <http://www.cidoc-crm.org/extensions/crmarchaeo/>
PREFIX afx:        <http://purl.allotrope.org/ontologies/property#>
PREFIX afr:        <http://purl.allotrope.org/ontologies/result#>
PREFIX qudt:       <http://qudt.org/schema/qudt#>
PREFIX rdfs:       <http://www.w3.org/2000/01/rdf-schema#>
PREFIX dcterms:    <http://purl.org/dc/terms/>
PREFIX obo:        <http://purl.obolibrary.org/obo/>

SELECT ?find ?findNumber ?context ?arsenic ?upperLimit ?notDetected ?unit ?publication WHERE {
  ?phase a crm:E4_Period ; rdfs:label "Arslantepe VIB1"@en .
  ?ctx crm:P8i_witnessed ?phase ; rdfs:label ?context . FILTER (lang(?context) = "en")
  { ?find crmarchaeo:AP21i_is_contained_in ?ctx }                       # a feature
  UNION
  { ?ctx crm:P53_has_former_or_current_location ?place .               # a site (finds without a feature)
    ?find crm:P53_has_former_or_current_location ?place }
  ?find a crm:E22_Human-Made_Object .
  OPTIONAL { ?find crm:P1_is_identified_by/crm:P190_has_symbolic_content ?findNumber }
  ?sampling crmsci:O3_sampled_from ?find ; crmsci:O5_removed ?sample .
  ?analysis afx:AFX_0000399 ?sample ; afx:AFX_0000395 ?result .
  ?result a afr:AFR_0002099 ; afx:AFX_0002816 obo:CHEBI_27563 .        # arsenic
  OPTIONAL { ?result qudt:numericValue ?arsenic }
  OPTIONAL { ?result afx:AFX_0000331/qudt:numericValue ?upperLimit }
  OPTIONAL { ?result crm:P2_has_type <https://lod-am.net/id/not_detected> . BIND (true AS ?notDetected) }
  OPTIONAL { ?result qudt:unit ?unit }
  OPTIONAL { ?analysis crm:P70i_is_documented_in/dcterms:identifier ?publication }
}
ORDER BY ?findNumber

Records documented in a publication

How many finds and analyses does each released publication document, and what is its DOI?

Columns: ?publication, ?citationKey, ?doi, ?finds, ?analyses. Conventions: literature (FaBiO, citation keys), finds and analyses documented in a publication.

Open in the query editor Source (05-records-of-a-publication.rq)

PREFIX crm:     <http://www.cidoc-crm.org/cidoc-crm/>
PREFIX dcterms: <http://purl.org/dc/terms/>
PREFIX prism:   <http://prismstandard.org/namespaces/basic/2.0/>
PREFIX afp:     <http://purl.allotrope.org/ontologies/process#>

SELECT ?publication ?citationKey ?doi (COUNT(DISTINCT ?find) AS ?finds) (COUNT(DISTINCT ?analysis) AS ?analyses) WHERE {
  ?publication a crm:E31_Document ; dcterms:identifier ?citationKey .
  OPTIONAL { ?publication prism:doi ?doi }
  OPTIONAL { ?find crm:P70i_is_documented_in ?publication ; a crm:E22_Human-Made_Object }
  OPTIONAL { ?analysis crm:P70i_is_documented_in ?publication ; a crm:E7_Activity }
}
GROUP BY ?publication ?citationKey ?doi
ORDER BY ?citationKey

Types of the LOD-AM typology and their Getty AAT matches

Which object types does the LOD-AM typology have, which broader type do they belong to, and how are they matched to the Getty AAT?

Columns: ?type, ?label, ?broader, ?matchKind, ?aat. Conventions: typology (SKOS concept scheme), matches to the Getty AAT (closeMatch, broadMatch).

Note: only the types used by released records are in the released data. Types without an AAT match have empty columns.

Open in the query editor Source (06-typology-and-aat.rq)

PREFIX skos: <http://www.w3.org/2004/02/skos/core#>

SELECT ?type ?label ?broader ?matchKind ?aat WHERE {
  ?type skos:inScheme <https://lod-am.net/id/typology> ; skos:prefLabel ?label . FILTER (lang(?label) = "en")
  OPTIONAL { ?type skos:broader/skos:prefLabel ?broader . FILTER (lang(?broader) = "en") }
  OPTIONAL {
    VALUES (?match ?matchKind) { (skos:exactMatch "exact") (skos:closeMatch "close") (skos:broadMatch "broad") (skos:narrowMatch "narrow") }
    ?type ?match ?aat . FILTER (STRSTARTS(STR(?aat), "http://vocab.getty.edu/aat/"))
  }
}
ORDER BY ?broader ?label
