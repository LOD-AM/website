SPARQL query

Write a SPARQL query against the released LOD-AM data and run it here, or start from one of the example queries. The data follow the LOD-AM conventions.

Endpoint: https://triple.lod-am.net/LOD-AM/sparql (read-only; queries stop after 120 seconds). Nothing is sent before you run a query. When you do, your browser sends the query to triple.lod-am.net, the LOD-AM triplestore. The editor keeps nothing in your browser after you leave the page.
