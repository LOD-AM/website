Data model

Every find, analysis, site and publication is a record with its own IRI under https://lod-am.net/id/. The diagram shows the main kinds of records and how they link.

It is an overview for orientation. The modelling rules, with every class and property, are in the LOD-AM conventions. To try the links out, start from the example queries.

The diagram as text
  • Site → located at → Place (crm:P53_has_former_or_current_location)
  • Feature → part of → Site (crm:P46i_forms_part_of)
  • Feature → dated to → Phase (crm:P8i_witnessed)
  • Phase → part of → Culture (crm:P9i_forms_part_of)
  • Phase → in system → Chronology system (skos:inScheme)
  • Chronology system → source → Publication (dcterms:source)
  • Find → found in → Feature (crmarchaeo:AP21i_is_contained_in)
  • Find → located at → Place (crm:P53_has_former_or_current_location), only for finds known by their site alone, without a feature
  • Find → material → Getty AAT concept (crm:P45_consists_of)
  • Find → type → Type (LOD-AM typology) (crm:P2_has_type)
  • Type (LOD-AM typology) → matches → Getty AAT concept (skos:closeMatch or skos:broadMatch)
  • Find → documented in → Publication (crm:P70i_is_documented_in)
  • Sampling → sampled from → Find (crmsci:O3_sampled_from)
  • Sampling → removed → Sample (crmsci:O5_removed)
  • Analysis → input → Sample (afx:AFX_0000399)
  • Analysis → output → Measurement (afx:AFX_0000395)
  • Measurement → quantifies → Element or nuclide (afx:AFX_0002816)
  • Analysis → carried out by → Laboratory (crm:P14_carried_out_by)
  • Analysis → documented in → Publication (crm:P70i_is_documented_in)

Ontologies and vocabularies

The released data use these ontologies and vocabularies. Getty AAT, ChEBI, Wikidata and ROR concepts are reused by their own IRIs. PeriodO and Pleiades are part of the model, but no released record uses them yet.
